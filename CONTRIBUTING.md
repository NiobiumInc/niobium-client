# Contributing

Thanks for your interest in this project. We're glad to have you.

## Issues are welcome

Bug reports, questions about behaviour and feature requests all help, so please
[open an issue](https://github.com/NiobiumInc/niobium-client/issues/new/choose). You do
not need to sign anything to open an issue.

## Pull requests

This repository does **not** accept pull requests from outside Niobium. If you
have found a fix, describe it in an issue. Please do not paste code into the
issue: we cannot use code that reaches us that way, and we would rather write
the fix ourselves from your description.

If you would like to contribute code to Niobium's open-source work, these
projects do accept pull requests (after a one-time Contributor License
Agreement at [https://cla.niobium.co](https://cla.niobium.co)):

- [niobium-client-fog-starter-kit](https://github.com/NiobiumInc/niobium-client-fog-starter-kit)
- [encrypted-nid](https://github.com/NiobiumInc/encrypted-nid)
- [encrypted-credit-card-fraud-detection](https://github.com/NiobiumInc/encrypted-credit-card-fraud-detection)
- [encrypted-set-membership](https://github.com/NiobiumInc/encrypted-set-membership)

## Reporting a security issue

Please do **not** open a public issue for a security vulnerability. Report it
privately as described in [SECURITY.md](SECURITY.md).

## Code of conduct

Be decent to each other. We reserve the right to decline interactions that
aren't.

## Questions

[Contact us](https://niobium.co/contact) — we're happy to help.
